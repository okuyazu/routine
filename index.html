Install this app

It installs straight from the browser — no app store, no account. It gets its own icon, opens full-screen, and works offline. Your data stays private on this device.

Android (Chrome): tap the ⋮ menu → Install app (or “Add to Home screen”).

iPhone / iPad (Safari): tap Share (□↑) → Add to Home Screen.

Desktop (Chrome/Edge): click the install icon (⊕ / monitor with ↓) at the right of the address bar.

Connect GitHub (optional)

The app already works fully on this device — nothing to set up. Connect GitHub only if you want to sync across devices and keep your notes as a Markdown/Obsidian repo. Paste a token; it's stored only on this device, never in the app or the repo.

  1. Open github.com → Settings → Developer settings → Fine-grained tokens.
  2. Repository access → Only select repositories → your benchmarks repo.
  3. Permissions → Contents: Read and write. Generate, then copy.
