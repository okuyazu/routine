# Idea Inbox that graduates into projects

Capture the important conclusions from long AI chats, accumulate them as rough ideas, then promote ripe ones into full projects with milestones.

## Notes
- End-of-chat capture emits a structured idea appended to the inbox
- The app shows an Inbox of rough ideas, kept separate from tracked projects
- 'Promote' turns an idea into a real project note with metrics + milestones
- Reuses the file-based, LLM-native flow the app already runs on

## Next steps
- Build Inbox UI + data model
- Add a reusable capture prompt for any AI chat
- Wire the promote-to-project flow
